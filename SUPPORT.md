# VeilBox Support

## Project Support

For bug reports, diagnostics, and privacy-related questions, use the project issue tracker:

`https://github.com/artem4150/VeilBox/issues`

## Before Reporting a Problem

Include:

- VeilBox version
- Windows version
- connection mode (`System Proxy`, `TUN`, `AmneziaWG` if applicable)
- whether the app was started with administrator rights
- a short problem description
- relevant local logs with sensitive values reviewed before sharing

## Recommended Diagnostic Notes

Useful details:

- selected profile type and engine
- whether `xray.exe`, `amneziawg.exe`, and `wintun.dll` are present
- whether the issue happens only in `TUN` or only in `System Proxy`
- whether the issue happens only after update / reinstall
