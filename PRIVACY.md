# VeilBox Privacy Policy

Last updated: March 29, 2026

## Summary

VeilBox is a local desktop VPN client for Windows.  
It does not require an account, cloud sync, or a hosted backend to function.

## What VeilBox Stores Locally

VeilBox stores the following data on the local device:

- saved VPN profiles and subscriptions
- application settings
- selected profile state
- local app and connection logs, if logging is enabled
- temporary runtime files required to start bundled VPN engines

This data is stored in the application's local Windows app-data directories.

## What VeilBox Sends Over the Network

VeilBox may connect to:

- user-selected VPN servers
- subscription URLs explicitly added by the user
- optional IP / country lookup or diagnostic endpoints used by in-app features

VeilBox does not operate the VPN servers configured by the user.

## No Account and No Telemetry by Default

VeilBox does not require user registration.  
VeilBox does not include telemetry, analytics, ad tracking, or cloud profile sync by default.

## Logs

If logging is enabled, VeilBox stores application and connection logs locally for diagnostics.  
Sensitive values are masked where practical, but logs can still contain connection metadata and server-related details.  
Users should review logs before sharing them with third parties.

## Data Retention

Local data remains on the device until:

- the user deletes profiles, logs, or settings
- the user uninstalls the application and chooses to remove local data

## Third-Party Components

VeilBox can use bundled third-party networking components such as Xray-core, Wintun, and AmneziaWG tooling.  
Those components are subject to their own licenses and privacy/security properties.
